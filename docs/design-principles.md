# EntityCraft Design Principles

1. **UI first** — every user-facing configuration is available in Home Assistant.
2. **No YAML required** — YAML may exist internally, but users never need it.
3. **Explainable automation** — every decision can answer why it did or did not run.
4. **Live evaluation** — the editor shows the current condition result and pending delays.
5. **Portable rules** — rule definitions never depend on a user's concrete entity IDs.
6. **Marketplace ready** — templates use declared inputs and local bindings from version 1.0.
7. **Home Assistant native** — use HA selectors, actions, config entries and entity patterns.
8. **Safe by default** — previewing or editing a rule never executes its actions.
